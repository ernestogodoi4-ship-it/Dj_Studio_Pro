# Melody Studio independente

O Melody Studio agora e um aplicativo Electron separado do DJ Studio PRO, com executavel, instalador, janela e perfil de dados proprios.

## Desenvolvimento

Instale Node.js LTS e execute `npm install` e `npm start`, ou use `ABRIR_EM_MODO_DESENVOLVIMENTO.bat`.

## Instalador Windows

Execute `GERAR_INSTALADOR.bat`. O instalador e gerado em `dist/` como `Melody_Studio_Setup_1.0.0.exe`.

No DJ Studio PRO, use o botao Melody Studio para abrir o app instalado. Projetos e preferencias ficam isolados no perfil do Melody Studio.
